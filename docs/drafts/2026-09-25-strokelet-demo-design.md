# Strokelet 首版 Demo 设计

日期：2026-09-25
目标环境：用户当前 Ubuntu 26.04 / GNOME Shell 50.1 / Wayland。
工作目录：`/home/xwp/strokelet`，规划时为空目录。

## 用户目标

在原生 Wayland 应用中选中文本，按住鼠标右键向上直线拖动，拖动过程中看见桌面轨迹，松开后复制当前选中内容。右击无拖动仍能打开普通上下文菜单。

## Demo 范围

- 固定触发键：右键。固定动作：发送一次 Ctrl+C。
- 固定手势：向上直线，不做模板录制、自由形状、按应用规则。
- 轨迹必须出现在当前应用上方；不以独立录制窗口内画线替代。
- 复制不读取剪贴板、不重新选中文本、不改变焦点；用手工粘贴验证结果。
- Ctrl+C 只适用于采用该复制快捷键的应用；终端的 Ctrl+Shift+C 暂不支持。
- 无 GUI 设置、常驻 systemd 服务、开机自启、deb 打包、任意命令执行。
- 鼠标设备由参数明确指定；首版支持相对位移鼠标，不支持触控板、绝对坐标设备、多鼠标并发。
- 用户可见 GNOME 指示器提供暂停和状态入口，不能假装完整设置 GUI 已实现。

## 选型和边界

Rust + evdev（同时使用其 uinput 支持）+ serde/serde_json + 单调时间 Instant。算法用普通二维点，不引入 ML、DTW、向量库。异步运行时不是硬依赖，使用有限超时的事件循环即可。

Rust 进程只在手工测试期间取得所选设备和 uinput 权限。禁止将日常用户加入可读取所有输入的 input 组；不运行 GUI 或任意用户命令为 root。运行参数固定允许控制的桌面 UID、session ID、所选设备，IPC 无任意输入注入接口。

GNOME 50 的 GJS 扩展使用 Shell UI 的非交互绘图层，提供真实屏幕指针轨迹和用户暂停入口。它不负责 evdev 识别，也不能被透明 GTK/egui 窗口替代。Shell 接口以本机 introspection/已安装资源为准，不假定 GNOME 46 接口仍有效。

初版采用 Unix socket。此阶段没有 GUI，但确定的协议可供后续 GUI 重用。后台发出开始、结束、取消事件；扩展在手势期间以约 60 Hz 获取 global.get_pointer() 的位置绘图。原始设备位移仅用于识别，不用于计算屏幕轨迹。快速起笔的显示起点存在 IPC/采样误差，目标为可用的实时视觉反馈，不声称逐硬件事件精确还原。

## 数据流

1. 扩展连接后台并确认轨迹层可用；后台确认指定 logind 会话处于活动、未锁定状态。
2. 后台抓取所选物理鼠标，正常事件由能力匹配的虚拟鼠标转发。
3. 右键按下被暂存，后台开始采集相对位移；扩展收到 Begin 后采集实际屏幕指针。
4. 指针移动仍转发给桌面，但手势中的右键按下/释放不传给应用，因此不弹菜单。
5. 松开右键后：小位移补发普通右击；有效上划发送 Ctrl+C；其他手势取消、不补发菜单。
6. End/Cancel 后立即清理轨迹。扩展断连、会话失活或权限检查失败立即停止识别并释放接管。

## 识别定义与状态

在 SYN_REPORT 边界合并 REL_X/REL_Y，坐标中向上为负 y。只用相对轨迹，保留方向。

状态为 Idle、Pending、Drawing、CancelledUntilRelease。Pending 中位移越过起步阈值后进入 Drawing；超过阈值之后不允许退回普通右击。

初始可调命令行参数：start_counts=12、min_up_counts=80、click_slop_counts=12、max_duration_ms=2500。counts 为原始设备单位，不是屏幕像素，README 必须解释 DPI 影响。

上划判据同时满足：终点 dy <= -min_up_counts；最大横向偏移 <= max(12, -dy * 0.30)；净上移/累计路径长度 >= 0.85。累计路径按每帧合并位移计算。阈值是 demo 初值，必须使用用户鼠标实测校准。

短右击要求整段轨迹最大离起点距离不超过 click_slop_counts，不能仅检查终点。下上往返不得误判为点击；左划、下划和明显折线不得触发复制。

滚轮或额外按钮发生在候选手势期间则取消手势；这些非右键事件仍按原有顺序正常转发。为保守处理复制动作，检测到物理修饰键按下时不注入 Ctrl+C；不增加对全部物理键盘的全局监听，而由桌面适配返回修饰键状态，在超时/未知状态下取消动作。

## 权限与退出

特权进程不执行 shell/用户命令。只允许固定 Copy 动作，且仅由物理手势触发。会话切换、锁屏必须取消识别；用 logind 查询指定 session 的 Active/LockedHint，并结合扩展会话状态；任何查询失败按不可用处理。注入前再次检查状态。

socket 目录 `/run/strokelet/<uid>/` 由服务创建，拒绝符号链接和非预期所有者；目录 root 所有、组为目标用户主组，0750；socket 所有者为目标 UID、0600；用 SO_PEERCRED 限制目标 UID 的连接。不覆盖既有不明路径。进程退出清理自己的 socket。

首次接管必须确认物理按键全松开，避免接管前后出现半次点击。停止时释放本进程注入的虚拟按键并关闭设备 FD；不得擅自释放物理键盘上的修饰键。先测试限时退出，再做完整试用；普通用户终端可通过扩展暂停或 Ctrl+C 结束前台测试，另备键盘切换 TTY 终止进程。

## 验收要求

- GNOME 文本编辑器、Firefox 原生 Wayland 会话：选中文本，上划时轨迹可见，松开后一次 Ctrl+C，手工粘贴内容正确。
- XWayland 应用作补充检查，不能代替原生 Wayland 验收。
- 右击不移动/轻微抖动：只出现一次菜单；上划时不出现菜单。
- 无选区时仍只发快捷键，不宣称复制成功；后台记录的是 CopyInjected，不是 ClipboardChanged。
- 连续 20 次上划至少 19 次正确触发；左右/下划每类 10 次不得复制。
- 暂停、扩展关闭、后台退出、设备拔插后无持续卡住的 Ctrl/鼠标按键；重新插入后首版要求手动重启，不自动接管陌生设备。
- 实测单屏缩放以及用户实际多屏环境；轨迹无抢焦点、无阻挡点击。未测试的布局明确记录。
