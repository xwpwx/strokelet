# Strokelet 鼠标组合键计划

**目标：** 按住触发键时再按另一个鼠标键，可以单独对应一条快捷键。例如触发键是右键时，「按住右键再按左键」可以是粘贴，右键画出的轨迹仍然是原来的规则。

**保留：** 全局仍只有一个触发键。轨迹规则、屏幕名称、快捷键录制、点击重放、滚轮取消、2.5 秒上限都不变。没有配组合键时，现在的行为不变：画轨迹仍按形状匹配；按住触发键时按下一个没有规则的键，仍取消这一笔，并把那个键交回应用程序。

**不在本计划内：** 三个及以上的键同时按下、先按左键再按右键、按住两个键再画一条单独的轨迹、把滚轮当成组合键、按应用程序使用不同规则。正式需求仍不承认设置界面；确认前不得改 `docs/official/`。

## 一条规则是什么

一条规则二选一：

- 轨迹：现有的点列（或旧的方向）加上快捷键。
- 组合键：触发键按住期间的另一个鼠标键，加上快捷键。

不能同时写轨迹和组合键。组合键只记录那一个额外键：`left`、`middle`、`forward`、`back`。它不能等于当前触发键。左键现在不能当触发键，但可以当这个额外键。

同一个额外键不能有两条规则。组合键和轨迹不会互相冲突，因为一个看键，一个看形状。规则总数仍然最多 16 条。

## 按下时怎么判定

触发键先按下。之后：

1. 只移动并松开：和现在一样。没超过点击阈值就重放触发键；画出的形状命中某条轨迹就注入那条快捷键。
2. 触发键还按着时，另一个鼠标键按下：
   - 有对应组合规则：立刻注入那条快捷键，不再拿这条手势去比轨迹。这个额外键的按下和松开都不交给应用程序。触发键后来松开时，也不再重放成普通点击。
   - 没有对应规则：和现在一样，取消这一笔，并把这个额外键交回去。
3. 先按左键、后按右键：左键是普通点击。右键按下后才开始新手势。顺序不能反。
4. 滚轮、超时、丢帧仍然取消，不注入组合键。

组合键在触发键按住的任何时刻都有效，包括已经开始移动之后。这时轨迹作废，只执行组合键。手稍微动一下也不会把「右键加左键」认丢。

## 用户怎么录

编辑规则时增加「按下鼠标组合」。演示正在运行时，向它要下一次组合，不另抢鼠标。演示没开时，短时独占鼠标。

提示：先按住触发键，再按另一个鼠标键。录到的是那个额外键。5 秒内没有按成、按了触发键自己、或按了 Esc，都不保存。

快捷键和屏幕名称仍用现有的两项。屏幕名称留空则不显示。

## 配置

```json
{
  "button": "left",
  "modifierCodes": [29],
  "keyCode": 47,
  "label": "Ctrl+V",
  "name": "粘贴"
}
```

`button` 与 `points` 或 `direction` 同时出现则拒绝。旧文件没有 `button`，读取结果和现在相同。

## 实施顺序

1. 用假输入测试组合键：按住右键再按左键且有规则时注入一次，左键不透传，松开右键不重放点击。没有规则时左键仍透传并取消。先左后右不算组合。滚轮仍取消。相同的额外键不能保存两次。
2. 配置接受 `button`。轨迹规则的读取和匹配不变。
3. 演示进程在额外键按下时先查组合规则，命中才吞掉该键并注入。`reload` 后换规则，不重新抓设备。
4. 设置窗口加上「按下鼠标组合」。演示开着时走已有的回传；没开时短时独占。
5. 保存一条「右键按住时按左键」，在编辑器里试一次。没有这条规则时，按住右键再按左键仍应能点到应用程序。

## 明确不做

- 不识别右键、左键、中键三者一起按住。
- 不把「先按左键再按右键」收成组合。
- 不给同一次按住再配一条必须画出的形状。
- 不改轨迹颜色、线宽和屏幕名称的显示时间。
