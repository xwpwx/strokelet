# Strokelet 首版 Demo 需求

## 目标与环境

在 Ubuntu 26.04 / GNOME Shell 50 Wayland 的原生应用中，用户选中文本后按住鼠标右键直线上划。拖动时，当前应用上方出现不抢焦点、不拦截点击的轨迹；松开后只发送一次 Ctrl+C。普通右击仍打开一次上下文菜单。当前目标环境已观察到 GNOME Shell 50.1 和 Wayland 会话；这不等于功能已验收。

## 首版范围

- 固定右键、直线上划和 Ctrl+C。设备由用户显式选择，首版只支持单个相对位移鼠标。
- 鼠标正常移动、左键、滚轮和额外按钮继续可用。有效上划不向应用发送右键按下/释放，因此不弹菜单。
- 轨迹是桌面全局覆盖层，显示真实屏幕指针位置。扩展提供暂停及连接状态入口。
- 不读取剪贴板、不改动选区、不主动切换焦点。无选区时仍只发送快捷键，不宣称剪贴板已改变。
- 扩展未就绪、连接断开、会话失活或锁定、权限检查失败时停止识别并安全释放设备；不得继续注入复制动作。

## 首版不包含

触控板、绝对坐标设备、多鼠标并发、自由形状识别、手势录制、按应用规则、终端 Ctrl+Shift+C、完整设置 GUI 和任意命令执行均不在首版范围。

## 安装包

`scripts/build-deb.sh` 打出的 deb 安装程序、GNOME 扩展和用户服务。安装后注销一次再登录。服务为当前用户准备 `/run/strokelet/<uid>`，用 logind 找到 Wayland 图形会话，并在只有一只可用鼠标时自动使用它。多只鼠标时，在设置里选择，或把路径写到 `~/.config/strokelet/device`。uinput 通过 udev 的 `uaccess` 交给当前会话，不把用户加入 `input` 组。

## 验收

- 在 GNOME 文本编辑器和 Firefox 的原生 Wayland 会话中，选中文本、上划并松开后，轨迹可见、菜单不出现、手工粘贴得到所选文本。XWayland 只能作为补充检查。
- 不移动或轻微抖动的右击只出现一次菜单。左划、右划、下划、明显折线、超时和取消均不得触发复制。
- 校准所选鼠标后，连续 20 次有效上划至少 19 次触发；左右/下划各 10 次均不触发复制。设备与阈值必须记录。
- 暂停、扩展关闭、后台退出、设备拔插和锁屏后，鼠标及虚拟 Ctrl 均不能保持按下；设备重新插入后首版由用户手动重启。
- 实测单屏缩放和用户实际多屏布局，确认轨迹不抢焦点、不遮挡交互；未测布局必须明确记录。

识别数值与边界见 [手势识别规格](../specs/gesture-recognition.md)；组件和安全边界见 [首版 Demo 架构](../design/strokelet-demo.md)。
